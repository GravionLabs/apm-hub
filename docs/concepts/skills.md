# Skills

This document explains what **Skills** are in the context of **GitHub Copilot CLI plugins**, how they are created from prompt templates, and how they differ from plain prompt files.

---

## What Is a Skill?

A **Skill** is a named, reusable prompt that is bundled inside a Copilot CLI plugin and distributed as part of it.

Skills answer the question:

> **"What reusable task can this plugin perform on demand?"**

When a plugin is installed, each of its skills becomes available as a **slash command** in supported IDEs and in the Copilot CLI:

```text
/csharp-async
/create-dotnet-solution
/ef-core
```

Skills are the plugin-scoped equivalent of `.prompt.md` files. Where a prompt file lives in `.github/prompts/` of a single repository, a skill lives inside a plugin and travels with it.

---

## Skills vs. Prompts

| Aspect              | Prompt (`.prompt.md`)          | Skill (`SKILL.md`)                        |
| :------------------ | :----------------------------- | :---------------------------------------- |
| **Location**        | `.github/prompts/` (per repo)  | `plugins/<plugin>/skills/<name>/SKILL.md` |
| **Scope**           | Single repository              | Any repository with the plugin installed  |
| **Distribution**    | Manual copy or sync script     | `gh copilot plugin install`               |
| **Source of truth** | Template file in `templates/`  | `plugin.config.yml` → generator           |
| **Trigger**         | `/prompt-name` (slash command) | `/skill-name` (slash command)             |
| **Versioning**      | Repository-level               | Plugin version                            |

**Key insight:** Every skill is backed by a prompt template. The plugin generator reads the template, optionally extends it with additional agent content, and writes the result as a `SKILL.md` file.

## The SKILL.md File

Each skill is stored as a `SKILL.md` file inside a named directory:

```
plugins/
└── csharp-development/
    └── skills/
        ├── csharp-async/
        │   └── SKILL.md
        ├── create-dotnet-solution/
        │   └── SKILL.md
        └── ef-core/
            └── SKILL.md
```

### SKILL.md Structure

A `SKILL.md` file consists of:

1. **YAML front-matter** — `name` and `description` fields consumed by the Copilot CLI
2. **Prompt body** — the full prompt instruction text, identical to the source `.prompt.md`

Example (`plugins/csharp-development/skills/csharp-async/SKILL.md`):

```markdown
---
name: csharp-async
description: 'Get best practices for C# async programming'
---

# C# Async Programming Best Practices

Your goal is to help me follow best practices for asynchronous programming in C#.

...
```

> **Note:** `SKILL.md` files are **auto-generated**. Do not edit them manually — always edit the source template in `templates/prompts/` and re-run the generator.

## How Skills Are Generated from Prompts

Skills are defined in `plugin.config.yml` under the `skills:` key and generated by `npm run generate`.

### Step-by-step

1. **Define the skill** in `plugin.config.yml`:

   ```yaml
   skills:
     - name: csharp-async
     - name: csharp-code-review
       extend:
         - agents/code-review-cli.agent.md
   ```

2. **Provide the source template** in `templates/prompts/`:

   ```
   templates/prompts/csharp-async.prompt.md
   ```

   The generator resolves `name: csharp-async` → `templates/prompts/csharp-async.prompt.md` automatically.

3. **Run the generator**:

   ```bash
   npm run generate
   ```

4. **Output** — the generator writes:

   ```
   plugins/csharp-development/skills/csharp-async/SKILL.md
   ```

   The `SKILL.md` contains the front-matter from the source `.prompt.md` plus the full prompt body.

### The `extend` field

A skill can incorporate additional content from one or more agent files:

```yaml
skills:
  - name: csharp-code-review
    extend:
      - agents/code-review-cli.agent.md
```

The generator appends the body of each listed file to the skill content (separated by `---`), producing a richer, composite prompt.

### Source Resolution

| Config entry                         | Resolved template path                            |
| :----------------------------------- | :------------------------------------------------ |
| `name: csharp-async`                 | `templates/prompts/csharp-async.prompt.md`        |
| `name: my-skill` (no source)         | `templates/prompts/my-skill.prompt.md`            |
| `source: prompts/my-skill.prompt.md` | `templates/prompts/my-skill.prompt.md` (explicit) |

## How to Use Skills

Skills become available as slash commands immediately after installing the plugin:

```bash
# Install the plugin (once per machine)
gh copilot plugin install csharp-development@copilot-hub

# Use a skill in Copilot Chat
/csharp-async
/create-dotnet-solution
/ef-core
```

In supported IDEs (VS Code, JetBrains), skills appear in the slash-command autocomplete list alongside regular prompts.

---

## How to Create a New Skill

1. **Write the prompt template** in `templates/prompts/`:

   ```
   templates/prompts/my-new-skill.prompt.md
   ```

   Give it a YAML front-matter with at minimum a `description` field.

2. **Register the skill** in the relevant `plugin.config.yml`:

   ```yaml
   skills:
     - name: my-new-skill
   ```

3. **Run the generator**:

   ```bash
   npm run generate
   ```

4. **Commit** both the template and the generated `SKILL.md`.
