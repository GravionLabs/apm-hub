## copilot-workspace

📁 [`plugins/copilot-workspace`](../plugins/copilot-workspace)

Setup and sync GitHub Copilot configuration from GravionLabs/copilot-hub. Provides an interactive wizard (gh-copilot-setup) to bootstrap .github/ with instructions, prompts, and agents tailored to your stack, plus a sync prompt (gh-copilot-sync) to keep them up to date. Includes create-agents-md to scaffold an AGENTS.md repository context file. The standalone scripts (copilot-sync.ps1, New-AgentsMd.ps1) are included for manual or scheduled runs without the AI prompt.

| Skill                                                                      | Description                                                                                                                                                                                                                                    |
| :------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`gh-copilot-setup`](../plugins/copilot-workspace/skills/gh-copilot-setup) | Interactive setup wizard: browse GravionLabs/copilot-hub, select relevant Instructions/Prompts/Agents, install them to .github/ and optionally to a global instructions directory, and generate a copilot-instructions.md                      |
| [`gh-copilot-sync`](../plugins/copilot-workspace/skills/gh-copilot-sync)   | Sync all existing .github/instructions, .github/prompts, and .github/agents files with the latest versions from GravionLabs/copilot-hub. Also syncs the global base directory (~/.github) if configured. Checks for newly available templates. |
