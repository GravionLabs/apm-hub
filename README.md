# github-copilot-templates

A shared **GitHub Copilot** templates repository with:

- Documentation (concepts, usage, best practices)
- Reusable **Custom Instructions**
- Reusable **Prompt files** (/slash commands)
- **Custom Agents** (specialized roles)

> Copy prompt and agent files into your project or reference them as examples.

## Quick start

- Explore \.github/copilot-instructions.md\ for repo-wide guidance
- Browse \.github/instructions/\*.instructions.md\ for scoped rules
- Try prompts in \.github/prompts/\*.prompt.md\ via Copilot Chat (e.g., \/explain-code\)
- Switch to a custom agent from \.github/agents/\*.agent.md\ in your IDE
