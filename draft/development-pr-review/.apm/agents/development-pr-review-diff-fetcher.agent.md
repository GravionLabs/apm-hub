## Purpose

Given a PR ID (and optionally a project/repo hint), fetch all metadata from ADO and produce a clean git diff ready for code analysis.

---

## Step 1 — Resolve PR Details

Use the ADO MCP tool to find the PR. If the repository is unknown, search across the project:

```
ado-repo_list_pull_requests_by_repo_or_project(
  project: "Generation and Operations",
  status: "Active",
  top: 200
)
→ find the PR matching the given PR ID
```

Or directly if repo is known:
```
ado-repo_get_pull_request_by_id(
  pullRequestId: <PR_ID>,
  repositoryId: <REPO_ID_OR_NAME>,
  project: "Generation and Operations",
  includeWorkItemRefs: true,
  includeLabels: true
)
```

**Extract and store:**
- `repository.project.name` → PROJECT_NAME
- `repository.id` → REPO_ID
- `repository.name` → REPO_NAME
- `repository.remoteUrl` → REMOTE_URL
- `sourceRefName` strip `refs/heads/` → SOURCE_BRANCH
- `targetRefName` strip `refs/heads/` → TARGET_BRANCH
- `title` → PR_TITLE
- `createdBy.displayName` → AUTHOR
- `lastMergeSourceCommit.commitId` → SOURCE_COMMIT
- `lastMergeTargetCommit.commitId` → BASE_COMMIT
- `workItemRefs[].id` → LINKED_WORK_ITEMS (array)

---

## Step 2 — Get Repository Remote URL

If `remoteUrl` was not included in the PR response:

```
ado-repo_get_repo_by_name_or_id(
  project: PROJECT_NAME,
  repositoryNameOrId: REPO_NAME
)
```

---

## Step 3 — Prepare Local Repository

Repository path convention: `C:\SOURCE_CONTROL\<PROJECT_NAME>\<REPO_NAME>`

```powershell
$repoPath = "C:\SOURCE_CONTROL\$PROJECT_NAME\$REPO_NAME"

if (Test-Path $repoPath) {
    cd $repoPath
    git fetch origin
    git fetch origin $TARGET_BRANCH
    git fetch origin $SOURCE_BRANCH
} else {
    git clone $REMOTE_URL $repoPath
    cd $repoPath
    git fetch origin $TARGET_BRANCH
    git fetch origin $SOURCE_BRANCH
}
```

---

## Step 4 — Get Git Diff

```powershell
cd "C:\SOURCE_CONTROL\$PROJECT_NAME\$REPO_NAME"
git diff "origin/$TARGET_BRANCH...origin/$SOURCE_BRANCH"
```

**If "unknown revision" error**, fall back to commit SHAs:
```powershell
git diff "$BASE_COMMIT...$SOURCE_COMMIT"
```

---

## Step 5 — Clean Diff Artifacts

Apply these cleaning rules:

1. **Strip diff prefixes** — Remove leading `+` from added lines and `-` from removed lines (keep `+++`/`---` file headers as-is).
2. **Reconstruct split values** — Reconstruct long strings/GUIDs wrapped across lines.
3. **Preserve file path and line numbers** — Extract from `diff --git` and `@@` markers.

**Language-specific rules after cleaning:**
- `.tf` files: `#` comments, `import { ... }` blocks, property assignments without commas are ALL valid HCL
- `.json` files: Reconstruct full structure from diff lines before validating
- `.yaml`/`.yml`: Preserve indentation after stripping `+`

---

## Step 6 — List Changed Files (Filtered)

**INCLUDE for analysis:**
- `.cs`, `.cshtml`, `.razor`, `.csproj`, `.sln`
- `.js`, `.jsx`, `.ts`, `.tsx`, `.vue`, `.svelte`, `.html`, `.css`, `.scss`
- `.py`, `.go`, `.java`, `.kt`, `.php`
- `.tf`, `.tfvars`, `.bicep`
- `.yaml`, `.yml` (CI/CD pipelines, Kubernetes, Helm)
- `Dockerfile`, `Dockerfile.*`
- `.sh`, `.ps1`, `.psm1`
- `.json` (production configs), `.xml`, `.config`, `.toml`
- `.sql`, `.md` (only in `.github/`)

**EXCLUDE:**
- `appsettings.Development.json`, `appsettings.Local.json`, `*.local.json`
- `docker-compose.yml`, `docker-compose.*.yml`
- `.env.local`, `.env.development`, `.env.test`
- `.designer.cs`, `.Designer.cs`, `.g.cs`, `.g.i.cs`
- Files in `/Migrations/`, `node_modules/`, `dist/`, `build/`, `bin/`, `obj/`
- `AssemblyInfo.cs`, files with `<auto-generated>` in first 10 lines
- `*.min.js`, `*.min.css`, `*.bundle.js`, lock files
