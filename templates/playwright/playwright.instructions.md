# Playwright Conventions

## Locator best practices

Use resilient locators in this priority order:

1. **`getByRole()`** — preferred; matches semantics not implementation
   ```typescript
   page.getByRole('button', { name: 'Submit' })
   page.getByRole('heading', { name: 'Dashboard' })
   page.getByRole('textbox', { name: 'Email' })
   ```
2. **`getByTestId()`** — explicit test hook; add `data-testid` to components
   ```typescript
   page.getByTestId('save-btn')   // <button data-testid="save-btn">
   ```
3. **`getByLabel()`** / **`getByText()`** / **`getByPlaceholder()`** — visible content
4. **CSS / XPath** — last resort; avoid class names generated by build tools

## Page Object Model (POM)

Encapsulate page interactions in classes — keep test logic out of locators:

```typescript
// pages/login.page.ts
export class LoginPage {
  constructor(private page: Page) {}

  async goto() { await this.page.goto('/login'); }

  async login(email: string, password: string) {
    await this.page.getByLabel('Email').fill(email);
    await this.page.getByLabel('Password').fill(password);
    await this.page.getByRole('button', { name: 'Sign in' }).click();
  }
}

// tests/auth.spec.ts
test('login with valid credentials', async ({ page }) => {
  const loginPage = new LoginPage(page);
  await loginPage.goto();
  await loginPage.login('user@example.com', 'password');
  await expect(page).toHaveURL('/dashboard');
});
```

## Test isolation

- Each test must be fully independent — no shared state between tests
- Use `test.beforeEach` for setup, `test.afterEach` for cleanup
- Never rely on test execution order
- Use `test.use({ storageState: ... })` for authenticated states (not shared login)

```typescript
test.use({ storageState: 'playwright/.auth/user.json' });
```

## Async/await patterns

```typescript
// ✅ Always await Playwright actions
await page.getByRole('button').click();
await expect(page.getByText('Success')).toBeVisible();

// ✅ Wait for state before interaction
await expect(page.getByTestId('modal')).toBeVisible();

// ✅ Parallel navigation + action
await Promise.all([
  page.waitForURL('/dashboard'),
  page.getByRole('button', { name: 'Continue' }).click(),
]);

// ❌ Never use arbitrary timeouts
await page.waitForTimeout(3000);  // flaky — use waitFor state instead
```

## Configuration (`playwright.config.ts`)

```typescript
export default defineConfig({
  testDir: './tests',
  fullyParallel: true,
  retries: process.env.CI ? 2 : 0,   // retries only in CI
  workers: process.env.CI ? 1 : undefined,
  reporter: [['html'], ['junit', { outputFile: 'results.xml' }]],
  use: {
    baseURL: process.env.BASE_URL ?? 'http://localhost:3000',
    trace: 'on-first-retry',          // capture trace on failure
    screenshot: 'only-on-failure',
    video: 'retain-on-failure',
  },
  projects: [
    { name: 'chromium', use: { ...devices['Desktop Chrome'] } },
    { name: 'firefox',  use: { ...devices['Desktop Firefox'] } },
    { name: 'webkit',   use: { ...devices['Desktop Safari'] } },
  ],
});
```

## CI integration

```bash
# Install browsers (once per CI agent image)
npx playwright install --with-deps chromium firefox webkit

# Run tests
npx playwright test --reporter=junit

# Upload trace artifacts on failure
```

## Naming conventions

- Test files: `<feature>.spec.ts` in `tests/`
- Page objects: `<page>.page.ts` in `tests/pages/`
- Fixtures: `<context>.fixture.ts` in `tests/fixtures/`
- Test IDs: `data-testid="<component>-<element>"` (kebab-case)
