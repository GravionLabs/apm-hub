## Key Conventions

- Source projects under `src/`, test projects under `test/`
- All async methods end with `Async`
- Null checks: `ArgumentNullException.ThrowIfNull(x)` / `string.IsNullOrWhiteSpace(x)`
- Exceptions: use precise types (`ArgumentException`, `InvalidOperationException`) — no base `Exception`
- No interfaces unless used for external dependencies or testing
- Least-exposure rule: `private` > `internal` > `protected` > `public`
- Do not edit auto-generated code (`*.g.cs`, `// <auto-generated>`, `api/**`)
- All NuGet versions in `Directory.Packages.props` — never inline in `.csproj`

---

## Test Conventions

- Test class: `[TestFixture]` with `[Category("UnitTest")]` (or `IntegrationTest` / `ManualTest`)
- Test method naming: `MethodName_ShouldExpectedResult`
- One behavior per test — no branching or conditionals inside tests
- Use `[TestCase]` for parameterized tests
- Assertions: **Shouldly** (`result.ShouldBe(expected)`)
- Mocking: **NSubstitute** (`Substitute.For<T>()`)
- No `using NUnit.Framework;` needed — globally imported via `test/Directory.Build.props`

## Build & Test Commands

```bash
dotnet build            # build solution
dotnet test             # run all tests
dotnet-coverage collect -f cobertura -o coverage.xml dotnet test  # with coverage
```

---

## Safe Change Checklist

- Run `dotnet build` and `dotnet test` before committing
- Do not set C# version newer than TFM default
- Do not change TFM, SDK, or `<LangVersion>` unless explicitly asked
- All NuGet package versions in `Directory.Packages.props`
- New public APIs need XML documentation comments
- Run `dotnet format` if a formatter is configured
