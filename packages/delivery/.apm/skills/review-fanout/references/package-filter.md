# Package filter

Step 1 keeps noise out of the package file. Exclude these paths from `git diff --stat` and `git diff -U10` with one pathspec each (`-- . ':!<pattern>'`; a pattern ending in `/` excludes the whole directory at any depth with `:!**/<dir>/**`). The same list applies to a PR (`gh pr diff`): drop the matching file sections. Binary files are dropped too (`git diff` prints `Binary files differ`; omit those sections).

Excluded patterns, one per line (tests parse this block, keep it one pattern per line):

```text
package-lock.json
pnpm-lock.yaml
yarn.lock
Cargo.lock
poetry.lock
uv.lock
packages.lock.json
__snapshots__/
*.snap
*.golden*
goldens/
*.min.js
*.min.css
*.bundle.js
*.map
dist/
coverage/
docs/*-list.md
```

## Notes

- Generated files: the `docs/*-list.md` files are generated by CI, never review them. Files with a `@generated` or `DO NOT EDIT` header are generated as well: drop them when the header is in the first 5 lines.
- Lockfiles and goldens are judged through the source change that causes them, so reviewers need not see them.
- Always add one line `filtered: <n> files (lockfiles, goldens, generated, binary)` to the package head with the number of dropped files.
